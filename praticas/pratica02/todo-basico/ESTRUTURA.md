| `package.json`      | Contém as informações do projeto, os pacotes/dependências utilizadas e os comandos que podem ser executados. |
| `package-lock.json` | Registra as versões exatas das dependências instaladas para manter o projeto consistente.                    |
| `App.js`            | É o arquivo principal da aplicação onde criamos a interface e o comportamento inicial do aplicativo.         |
| `app.json`          | Contém as configurações do projeto Expo, como nome, versão, ícone e outras configurações do aplicativo.      |
| `assets/`           | Guarda arquivos utilizados pelo aplicativo, como imagens, ícones e fontes.                                   |
| `node_modules/`     | Contém os pacotes e dependências instalados pelo NPM que o projeto precisa para funcionar.                   |
| `.gitignore`        | Define arquivos e pastas que o Git deve ignorar e não enviar para o repositório.                             |
| `.expo/`            | Guarda arquivos e informações temporárias geradas pelo Expo durante o desenvolvimento local.                 |
