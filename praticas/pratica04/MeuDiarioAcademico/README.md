# Meu Diário Acadêmico

Aplicativo desenvolvido em React Native com Expo para a disciplina de Programação para Dispositivos Móveis.

## 📚 Sobre o projeto

O aplicativo "Meu Diário Acadêmico" possui uma tela inicial para cadastro rápido de disciplinas do semestre.

Nesta atividade foram trabalhados conceitos fundamentais de interface de usuário (UI), componentes do React Native, organização de código, StyleSheet e Flexbox.

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Native Safe Area Context

## 📱 Funcionalidades

- Exibição do título do aplicativo;
- Campo para informar o nome da disciplina;
- Botão "Adicionar";
- Exibição da lista de disciplinas;
- Organização da interface utilizando Flexbox;
- Utilização de componentes do React Native;
- Separação dos textos da interface no arquivo `labels.js`.

## 📂 Organização dos arquivos

- `App.js` — contém a interface principal do aplicativo.
- `labels.js` — contém os rótulos utilizados na interface.
- `package.json` — contém as configurações e dependências do projeto.
